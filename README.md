# ふよみ

大人のバイオリン初心者が、五線譜の4音を左から一音ずつ読み、実際に弾いて確かめるための小さなWebアプリです。拍やテンポは判定せず、「音符の位置を見て、対応する音を出す」という譜読みの土台に絞っています。

ビルド工程と外部依存はありません。ブラウザ内で動き、マイクの音声を保存・送信しません。

## ゆびいろとの違い

姉妹アプリ「ゆびいろ」は、弦の色と指番号を見て一音を弾く入口です。ふよみはその次の段階として、通常の五線譜に書かれた4音を読みます。

- 出題は弦の色ではなく、ト音記号・調号つきの五線譜
- 一問は一音ではなく、4音の短いフレーズ
- 鍛える対象は、音符から第1ポジションの音へ変換する力
- 演出は音符の静かな色変化と短い和音だけ
- 音程の針、セント表示、点数は出さない

## レベル

高い弦から1本ずつ覚え、そのあと弦を組み合わせます。

1. ミ線だけ。0〜3の指
2. ラ線だけ。0〜3の指
3. レ線だけ。0〜3の指
4. ソ線だけ。0〜3の指
5. 選んだ2本。0〜3の指
6. 選んだ弦（1〜4本）。4の指まで
7. 4本ぜんぶ。0〜3の指
8. 4本ぜんぶ。4の指まで

レベル5と6では、設定画面に弦のボタンが出ます。レベル5は必ず2本で、3本目を押すと先に選んだ弦と入れ替わります。

4の指は、隣の開放弦と同じ高さになります。マイクは音高だけを聞くため、実際にどの弦を使ったかは本人または講師が確かめます。

## 弦の色と指番号

譜面の音符を弦の色で塗り、指番号を音符の上に出します。色はゆびいろと同じ、ソ線が青、レ線がオレンジ、ラ線が赤、ミ線が緑です。

設定「弦の色と指番号」で3段階に切り替えられます。

- 色と指番号を出す（既定）
- 色だけ出す。指番号を消し、弦だけを手がかりに残す
- 出さない。五線だけを読む

指番号は五線の上に一列で並び、上加線へ出た音のところだけ持ち上がります。外した直後の音だけは弦の色を使いません（ミ線の緑と「合っていた」の緑を混ぜないため）。

## 設計上の決めごと（変える前にここを読む）

- 最優先の決定記録は `docs/decisions.md`。次に `SPEC.md`、`CONTRACT.md` を参照する。
- 正解は「目標の音高が出たこと」。弦と指を判定したとは表示しない。
- ヒントは既定で出さない。「わからない」を押すたび、現在音だけ音名、次に推奨運指を開く。外したときは音名まで自動で開く。
- 合格時は手を離さず自動で次へ進む。外しても同じ音を続ける。
- 開始直後に音の確認を置く。マイクが使えない、または音を確認できない場合は、音を聞かない自己確認モードへ移れる。
- 一問は4音固定。順次進行を主体にし、跳躍は4度まで、1フレーズに最大1回。
- ト音記号・臨時記号・符頭はBravura 1.204の字形輪郭をSVGパスとして埋め込み、実行時のフォントに依存しない。
- 出題範囲は選んだレベルに従うが、判定候補には現在の調で第1ポジションから出せる4弦すべての音高を渡す。
- 合否や「とばす」の後は、無音または新しい弾き始めを観測するまで次の判定を再武装せず、持続音を次へ持ち越さない。
- おてほんや完了音を鳴らしている間は、マイク判定を止める。
- 結果に出すのは観測した事実だけ。自動診断、音程点、「レベル合格」は出さない。
- `?level=3&key=A&hint=off&n=5&marks=color&strings=DA` のようなURLで、講師が条件を固定できる。`strings` は弦を選べるレベル（5・6）でだけ効く。
- 設定と初回説明の確認状態は、`localStorage` の `fuyomi` に保存する。

## 検証済みと未検証

検証済み:

- `node tests/run.mjs` の全82件が成功し、exit 0。音楽理論、フレーズ生成、合成音のピッチ検出、保持判定、状態機械、五線譜SVG、弦の色と指番号を確認
- Google Chrome 151のヘッドレスを `--use-fake-ui-for-media-stream --use-fake-device-for-media-stream` 付きで起動。Web Audio合成MediaStreamをマイク入力へ注入し、設定 → 音の確認 → マイク練習3フレーズ → 結果まで完走
- 同じChromeで `?level=4&key=D&hint=off&n=3` を完走し、指定値の固定と、レベル外のラ線開放音を別音として退けることを確認
- 「わからない」1回目で音名、2回目で推奨運指が開き、次の音で閉じることを確認
- 合格音を伸ばし続けても次の音へ判定を持ち越さず、無音後の新しい発音で進むことを確認
- 最終音の完了演出中に「やめる」を押し、1.8秒後も結果画面が出ず設定画面に留まることを確認
- 375 × 667、390 × 844、430 × 932pxの通常マイク状態と音を聞かない状態で、縦横スクロールなしを確認
- `prefers-color-scheme: dark` に応じて画面と五線譜SVGがdarkテーマになることを確認
- 上記ブラウザ経路でJavaScript例外、`console.error`、`console.warn` がすべて0件であることを確認

未検証:

- Chrome 151ヘッドレスのネイティブ偽音声デバイス。上記2フラグでデバイスは列挙できたが、`getUserMedia({audio:true})` が完了しなかったため、通し確認ではWeb Audio合成MediaStreamを使った
- 実バイオリンと実iPhone Safariを組み合わせたマイク判定
- 実機でのマイク許可拒否、端末差、周囲音がある場所での復帰導線
- おてほん音と完了和音の実機での音量・音色
- 実際の生徒が譜面台の距離から見た視認性と操作性

## 動かし方

リポジトリ直下でローカルサーバーを起動します。

```sh
python3 -m http.server 8819
```

ブラウザで `http://localhost:8819/` を開きます。静的ファイルだけなので、そのままGitHub Pagesにも配置できます。

契約テストは次で実行します。

```sh
node tests/run.mjs
```
